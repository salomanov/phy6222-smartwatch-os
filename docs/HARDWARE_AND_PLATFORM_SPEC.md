# Полная аппаратная спецификация и база знаний: Смарт-часы LP715 / LP719 на SoC PhyPlus PHY6222

## 1. Общие сведения и идентификация платформы
- **Маркировка платы**: `LP715_MB_V1.3` (ревизия шелкографии от `2022-06-02`).
- **Заводская модель прошивки (по строкам ROM/дампа)**: **`LP719`** (`Nov 4 2022 11:35:24`, ID платформы `PHY+62XXPLUS0504`).
- **Аналоги и родственные устройства**:
  - Фитнес-браслеты Smart Band M4 / M5 / M6 / M7 / M8 (платформы FitPro, Lefun Health, HryFine).
  - Смарт-часы D20 / Y68 / 116 Plus на чипах PhyPlus PHY6202 / PHY6212 / PHY6222.
  - Умные вейпы с цветными дисплеями (Geekvape, Smok, Vaporesso и др. на базе тех же контроллеров PhyPlus M0/M3).

---

## 2. Микроконтроллер (SoC) — PhyPlus PHY6222QC
- **Архитектура**: 32-bit ARM Cortex-M0 (ARMv6-M Little Endian).
- **Тактовая частота**: 16 МГц (основной кварцевый резонатор `M16.00 Ch 32`), встроенный PLL до 64 МГц / 96 МГц.
- **Низкочастотный источник**: Внутренний RC-генератор 32.768 кГц (`CLK_32K_RCOSC`) с аппаратным автотрекингом (`hal_rc32k_clk_tracking_init`).
- **Память SRAM**: 138 КБ (разделена на банки `RET_SRAM0`, `RET_SRAM1`, `RET_SRAM2` с управлением retention в deep sleep).
  - Базовый адрес SRAM: `0x1fff0000` (таблица векторов и прыжков ROM jump table занимает первые 1024 байта).
- **Встроенная Flash-память**: 512 КБ (Flash ID: `0x1360EB` - Gigadevice/XTX 4 Мбит).
  - Считывание через XIP SPI Flash-контроллер (`XFRD_FCMD_READ_DUAL` на 64 МГц).
- **Радиомодуль BLE**:
  - Bluetooth Core Spec 5.2 (1 Mbps, 2 Mbps, Long Range Coded PHY, Advertising Extensions).
  - Мощность передатчика: настраиваемая от -20 dBm до +10 dBm (по умолчанию `0 dBm`).
  - Аппаратный контроллер пакетов Baseband (`BB_IRQn`, TIM1, TIM2, TIM4).

## 3. Физическая топология контактных площадок (Тестпоинты на плате)
Расположение контактов слева направо вдоль верхнего края платы:
- **Группа 1 (слева от шлейфа дисплея)**:
  1. `GND` — Общая земля (минус питания).
  2. `TX` — UART TX микроконтроллера (**Pin 8 чипа**, P09) -> подключается к **RX** USB-UART адаптера.
  3. `VCC` (`VCC3V`) — Питание логики 3.3В чипа.
  4. `GND` — Земля.
- **Шлейф дисплея (QSFX09617 HY KA3)**
- **Группа 2 (справа от шлейфа дисплея)**:
  5. `RX` — UART RX микроконтроллера (**Pin 9 чипа**, P10) -> подключается к **TX** USB-UART адаптера.
  6. `HR` — Аналоговый/цифровой сигнал датчика пульса (Heart Rate, не путать с UART!).
  7. `VBUS` — Вход зарядки +5В от встроенного USB-штекера.
  8. `TM` — Test Mode / Boot Pin (**Pin 7 чипа**). При подаче 3.3В переводит чип в режим UART-загрузчика `cmd>>:`.
  9. `EN` — Аппаратный сброс (Reset, активный низкий уровень).
  10. `BT` — Плюс Li-Po аккумулятора (~3.7–4.2В).

## 5. Дисплей ST7735S (0.96" TFT 80x160)
- **Точные аппаратные параметры, извлеченные из заводского дампа**:
  - Разрешение: **80 x 160 пикселей**.
  - Формат цвета: RGB565 (16 бит на пиксель, Big Endian).
  - Смещение окна контроллера: `colstart = 26`, `rowstart = 1`.
  - Инверсия: **ВКЛЮЧЕНА (`INVON` - 0x21)** для правильной цветопередачи IPS-матрицы.
  - Порядок адресации памяти MADCTL (0x36): `0xC8` (BGR, инверсия осей X/Y для вертикальной портретной ориентации).

## 6. Карта Flash-памяти (512 КБ / 0x80000 байт)
| Адресный диапазон | Размер | Назначение |
|---|---|---|
| `0x11000000 - 0x11000FFF` | 4 КБ | Заводской Bootloader / Информационный сектор чипа |
| `0x11001000 - 0x11001FFF` | 4 КБ | Заголовок разделов прошивки (Partition Table, FCT) |
| `0x11002000 - 0x1103AFFF` | ~228 КБ | Основной исполняемый раздел прошивки (Application Code) |
| `0x1103B000 - 0x11053FFF` | ~100 КБ | Шрифты (PHY_FONTV1.01.03GB12EU12) и графика циферблатов |
| `0x11054000 - 0x1107DFFF` | ~168 КБ | Резервный банк OTA обновления (Single Bank / Dual Bank) |
| `0x1107E000 - 0x1107FFFF` | 8 КБ | Энергонезависимые настройки пользователя и калибровки (SNV) |

## 7. Протокол проводного Bootloader чипа PHY6222 (`cmd>>:`)
Чип переходит в режим загрузчика при подаче питания при подтянутом к 3.3В контакте `TM`:
- Скорость: **115200 бит/с**, 8 бит, без чётности, 1 стоп-бит.
- Приглашение: `cmd>>:`.
- **Основные команды загрузчика**:
  - `rdreg <addr>` — чтение 32-битного регистра (например, `rdreg 4000f018`).
  - `wrreg <addr> <val>` — запись регистра.
  - `flash id` — чтение JEDEC ID Flash-памяти (возвращает `1360eb`).
  - `flash ver` — версия ROM-загрузчика (возвращает `001360eb 6222M005`).
  - `flash erase <offset> <len>` — стирание секторов (блоками по 4096 байт).
  - `flash write <offset> <data>` — прямая запись данных в Flash.
  - `flash read <offset> <len>` — чтение Flash (использовалось для снятия `factory_dump.bin`).
